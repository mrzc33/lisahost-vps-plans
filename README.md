## 实测数据能说明什么

以下每组数字都对应某款套餐的某一次测试，机器、时段、测速节点都不同，别把不同套餐的延迟当成精确排名。

**9929 精简版（1核 1G / 10G / 50M / 1T）的一次实测**：Intel Xeon E5-2680 v4，Geekbench 5 单核 420、多核 446，1G 内存外带 512MB Swap，NVMe 64K 读写 1.73GB/s、4K 209.79MB/s。Ping 电信 175ms、联通 171ms、移动 176ms，三者差距在 5ms 以内，洛杉矶本地 6ms。去程三网都从美国圣何塞接入 Cogentco 到洛杉矶，没有绕日本或欧洲；回程电信、联通走 AS9929，移动走 AS9808（CMIN2）。国内上下行接近 50M 标称带宽。

**4837 300M 那台同系列机器的一次实测**：同样是 E5-2680 2.4GHz，磁盘 I/O 428MB/s，本地 Ping 平均 196ms，全国均值 197ms（电信 189、联通 197、移动 208），国内外节点基本无丢包，上传下载能跑满 1000Mbps，ipinfo 判定为双 ISP。这组数据说明 4837 的瓶颈不在带宽，在延迟。

**洛杉矶家宽 VDS 基础款的一次实测**：硬盘 I/O 三次平均 405.7MB/s，单核综合 438.9，国外节点基本零丢包、国内部分地区少量丢包，IP 定位美国加州洛杉矶原生 IP，Disney+、Netflix、YouTube、Amazon Prime Video 均可解锁。

三条线的延迟大致在 175ms 到 197ms 之间浮动，差距 20ms 上下，带宽却差 6 倍。这就是 9929 和 4837 之间真正的取舍。

## IP 质量：双 ISP 住宅、原生、机房是三件事

机房 IP 在 TikTok、Instagram、亚马逊的风控里几乎是明牌。原生 IP 解决了“归属地”问题，但 ASN 仍可能挂在机房名下。双 ISP 住宅 IP 连 ASN 和运营商信息都显示为真实家庭宽带，平台看到的是一个当地家庭用户。

9929 那台机器的 IP 经 IPinfo、ipregistry、ipapi、AbuseIPDB 多个库查询，类型都判定为 Residential，属美国原生 IP。可解锁 Netflix、Disney+、YouTube Premium、Amazon Prime Video、Spotify、ChatGPT，另有资料补了 HBO Max、ESPN 和 TikTok。

一个容易踩的坑：非原生 IP 的廉价年付套餐解锁能力明显弱。买之前看套餐描述里有没有“原生 IP”“双 ISP”这几个字，没有的话别指望它跑流媒体。

## 限制与不适合的人

**50M 带宽是硬天花板。** 9929 全线起步 50M，做图文、账号维护、看流媒体没问题，跑视频上传和大量并发就得上 4837 或家宽 VDS。

**CN2 默认不是原生 IP。** 月付要加 20 元，年付可免费换，下单后提工单，别忘了这一步。

## FAQ

**能装 Windows 吗？**
4837 线路和家宽住宅 VDS 系列支持，9929 和 CN2 GIA 只支持 Linux。下单前在购买页确认一遍。

**IP 被封了怎么办？**
提工单申请更换，通常 24 小时内处理。新机器 48 小时内可免费换一次，之后视情况收费。

**9929 一期和二期有什么区别？**
线路相同，IP 段和计费策略不同。一期是双 ISP 住宅 IP 段（39.71 段），支持月付；二期是 206 段的小众原生 IP，季付更划算。

**支持支付宝吗？**
支持支付宝和 USDT，付款后即时自动开通。

**48 小时退款怎么算？**
从服务开通起算，48 小时内可申请全额退款，原路退回。大额消耗流量或存在滥用的订单除外。

**优惠码能和年付折扣叠加吗？**
9 折码在结算页填入即生效，与季付、年付、二年付折扣的叠加规则以下单页实际计算为准。

**洛杉矶家宽 VDS 和 9929 双 ISP 差在哪？**
9929 卖的是双 ISP 属性的原生 IP 加优质回程，适合国内访问；家宽 VDS 卖的是真实民居宽带分配的静态住宅 IP，IP 质量更高但非大陆直连优化，要配中转。

**只做外贸网站，需要买住宅 IP 吗？**
不需要。CN2 GIA 带 50G 防御、三网直连，建站更合适，机房 IP 对网站没有负面影响。
